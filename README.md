# Lettuce

Lettuce is a lightweight desktop companion for Roblox Studio that makes replacing animations quick and automatic.

Install the app, connect your Roblox account, and run the Lettuce Studio plugin. The plugin finds supported animation references in the open place, Lettuce handles the upload queue, and the new asset IDs are applied back in Studio automatically.

## Features

- Roblox sign-in through OAuth 2.0 with PKCE
- Automatic animation discovery and replacement
- Concurrent uploads with progress, retries, and logs
- Lightweight Studio plugin with a local-only connection
- Automatic desktop and plugin updates
- Secure session storage in the operating-system credential vault

## Download

Download the latest Windows installer and Studio plugin from [GitHub Releases](https://github.com/svvly2/lettuce/releases/latest).

Roblox Studio must have **Allow HTTP Requests** enabled for the plugin to connect to Lettuce.

## Built with

React, TypeScript, Electron, Go, and Luau.
